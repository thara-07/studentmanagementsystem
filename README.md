# Student Management System
A simple, graphical desktop application built with Java Swing to manage student records. This project serves as a comprehensive demonstration of core Java concepts including Object-Oriented Programming (OOP), Event-Driven GUI design, File I/O, and Multithreading.

# Features
Add Student: Enter details (ID, Name, Department, Year, CGPA) to add a new student. Includes input validation.

Search Student: Retrieve and display a student's details using their unique ID.

Update Student: Modify the details of an existing student.

Delete Student: Remove a student record from the system.

Display Records: View all currently loaded student records in a formatted text area.

Save to File (Data Persistence): Save all student records to a local text file (students.txt) using a background thread.

Dark Mode UI: Features a custom dark theme interface for better visibility and modern aesthetics.
